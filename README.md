# ⚡ Apex Electrical Services — Manchester, UK

A high-performance, conversion-focused single-page web platform engineered for a certified 24/7 emergency electrical contractor in Greater Manchester, UK.

🔗 **Live Website:** [https://apexelectricalmanchester.vercel.app](https://apexelectricalmanchester.vercel.app)

---

## 🎯 Project Overview & Business Value

Local trade services in the UK lose significant emergency call-out revenue due to slow mobile loading speeds and poor Google Maps indexing. This project was architected to solve that:

- **Mobile-First Emergency Conversion:** Sticky 1-tap dialer for instant dispatch calls.
- **Fixed-Price Transparency:** Clear UK trade pricing structures that eliminate customer hesitation.
- **Sub-Second Load Times:** Built using clean React + Tailwind with WebP asset optimization to achieve 95+ Google Lighthouse scores.
- **Local SEO & AI-Search Ready:** Embedded `Schema.org` JSON-LD structured data (`@type: Electrician`), UK geo-coordinates (Manchester `M3 2JA`), and canonical tags for Google Local Map Pack and AI engine discovery.

---

## 🛠️ Tech Stack & Optimization

- **Frontend:** React 19 + Vite
- **Styling:** Tailwind CSS (Modern Dark Charcoal / High-Contrast Amber)
- **Icons:** Lucide React
- **SEO & Indexing:** Schema.org JSON-LD LocalBusiness, robots.txt, XML sitemap
- **Assets:** Squoosh-compressed WebP format (< 100 KB total payload)

---

## 📍 Key Features

1. **24/7 Rapid Dispatch Bar:** Sticky emergency calling mechanism.
2. **Interactive Emergency Quote Form:** Postcode-aware with emergency priority toggles.
3. **Verified Trade Credibility:** NICEIC, City & Guilds Level 3, and £5M Liability badges.
4. **Local Manchester Targeting:** Didsbury, Salford, Altrincham, and Central Manchester suburb indexing.
5. **Interactive FAQ Accordion:** Addresses common call-out pricing and certification queries.
